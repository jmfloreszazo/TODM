## Important limitations / pending external work

- The artifact is a **synthetic engineering demonstration**, not an industrial controlled study or evidence of comparative superiority.
- SBVR, DMN, BPMN, CMMN and OCL are represented by **limited JSON semantic profiles**, not complete OMG engines.
- Public demo Ed25519 keys/signatures do not authenticate real-world human identities.
- The [arXiv submission](../paper/ARXIV_SUBMISSION.md) has **not** been completed; neither an arXiv identifier nor an acceptance decision exists.
- No permanent archive DOI has been issued; see [DOI guidance](DOI_ARCHIVE.md).
- The tagged **v1.2** release is an immutable earlier snapshot. Documentation corrections on `main` postdate that tag; do not describe them as part of v1.2. If archival consistency requires these corrections in the release ZIP, publish a **new** tag rather than mutating v1.2.
- A LaTeX build can differ at the byte level across toolchains. Reproducibility currently concerns successful compilation, contents and behavioral fixtures, not identical PDF SHA-256 across environments.
- Visual inspection sampled the first and last pages; it was not a manual typesetting inspection of every page.
