## Suggested deposit workflow

1. Sign in to a trusted research preservation service such as [Zenodo](https://zenodo.org/).
2. If using Zenodo's GitHub integration, authorize your GitHub account and enable the `jmfloreszazo/TODM` repository for release archiving. Verify that the existing release can be imported; if not, create a subsequent versioned release under a controlled process.
3. Review the archived file list, authorship, title, research artifact type, keywords, license, version and funding/affiliation details.
4. Publish the archive and obtain the **actual** DOI from the preservation service.
5. Confirm the DOI resolves to the intended immutable version, and update `CITATION.cff`, README and paper availability statements.

A GitHub tag or release URL is **not** itself a DOI. Do not invent an identifier or state that a DOI has been registered before verifying the archival record.
