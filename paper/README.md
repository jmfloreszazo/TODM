# TODM research manuscript — v1.5 development

The v1.5 manuscript is staged as [Markdown](TODM_Paper_v1.5.md) and [LaTeX](source/v1.5.tex). The [v1.5 PDF](TODM_Paper_v1.5.pdf) is generated by [GitHub Actions](../.github/workflows/paper-pdf.yml); its availability must be confirmed before publication.

The [published v1.4 PDF](TODM_Paper_v1.4.pdf) and [v1.4 manuscript](TODM_Paper_v1.4.md) remain preserved as prior research versions. **No DOI, peer-review acceptance, full OMG implementation or industrial outcome is claimed.**

## Build v1.5

```bash
cd paper/source
latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error v1.5.tex
```

See [publication status](../docs/PUBLICATION_STATUS.md), [reproducible demo](../demo/README.md) and [versioning](../docs/VERSIONING.md).
