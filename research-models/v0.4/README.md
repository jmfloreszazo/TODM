# TODM five-family model profiles — v0.4 illustrative subset

These five JSON files expose the **limited operational profiles** used to discuss SBVR-derived rules, BPMN event traces, CMMN case constraints, DMN-like decisions and OCL-inspired invariants. They are **not complete or certified OMG implementations**.

These model profiles are **reference data only** in the current public repository: the minimal `src/todm_demo.py` and `dotnet/Todm.Seed` do **not** execute all five profiles. The full v0.4 evaluator, tests, signatures and fixtures are pending publication as tracked in [issue #1](https://github.com/jmfloreszazo/TODM/issues/1).

The research question is whether independently approved oracles can detect correlated specification-and-implementation defects. This does not imply that any of these files were approved by a real human signatory.
