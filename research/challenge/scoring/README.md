# S1 experiment scoring contract (no measurements included)

This is an **analysis utility**, not an executed benchmark. It accepts externally obtained, independently adjudicated case-level observations. No agent outputs, human observations, costs or research conclusions are generated by this folder.

Run from repository root:

```bash
python3 -m unittest discover -s research/challenge/scoring -p 'test_*.py' -v
python3 research/challenge/scoring/score_s1.py observations.json --output metrics.json
```

Input `observations.json` is an array of objects with `task_id` and `case_id` nonempty strings, `arm` in `S1-A`, `S1-B`, `S1-C`, `defect_present` a true JSON boolean from adjudicated ground truth, and `verdict` in `PASS`, `FAIL`, `INCONCLUSIVE`. One observation per (task, case, arm); duplicates are rejected. Names and assignments follow [BASELINES.md](../BASELINES.md).

Scores use a defective case flagged `FAIL` as TP and a defective case `PASS` as FN; clean case `FAIL` is FP; clean `PASS` is TN. `INCONCLUSIVE` is reported separately and **never counted as PASS**. Decisive-only rates exclude INCONCLUSIVE and must always be read alongside its rate and the conservative count of possible escaped defective cases. Undefined denominators result in JSON `null`, not misleading zero. Counts are descriptive, not confidence intervals. The tool does not yet perform paired task-level bootstrap or evaluate mutation equivalence.

**Critical limitations:** Input labels are trusted, not verified. No code in this folder demonstrates a frozen preregistration, blind adjudication, independent oracle provenance, real agent execution or matched randomization. Those require externally collected artifacts and reviewers. Do not publish these utility tests as S1 findings.

When real observations become available, preregister the primary endpoint, costs and treatment of INCONCLUSIVE before looking at them. Hash and archive the raw input and analysis code. Report paired task-level analyses rather than treating every case record as an independent study unit.
